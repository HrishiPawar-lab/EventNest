# Eventnest agent workspace

This directory holds guidance for people and coding agents working on Eventnest.

- [`architecture/project.md`](architecture/project.md) summarizes the agreed stack, application boundaries, data model, and open decisions.
- [`skills/`](skills/) is reserved for reusable project specific skills. Put each skill in its own directory with a `SKILL.md` entry point.

The root [`AGENTS.md`](../AGENTS.md) explains how to use these files while working in the repository.
